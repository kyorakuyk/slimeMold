Fourfold · TaskGraph Worker 内部时序

这张图描述实际成功 Run 的事实链：TaskGraph 定义任务，WorkerQueue 管理 lease，Host 创建 Worktree，官方 Codex Worker 修改代码，Host Acceptance 决定成功，Evidence/Receipt 才进入 Delivery。右侧虚线区域是普通 Workflow 节点图，不是本次 Worker 成功的事实源。

Success authority

Host Acceptance + durable Evidence/Acceptance decides TaskSucceeded. Codex's final message is only an input to acceptance.

Recovery authority

Event stream + side-effect journal are rehydrated after restart. Retry creates a new attempt; failed history is retained.

Important boundary

Workflow node graph ≠ TaskGraph Worker. A red node in the generic workflow canvas does not invalidate this Worker Run, and a green Worker Run does not validate that canvas.
