# 历史文档

本目录保存已经完成阶段、早期评审、旧验证清单和讨论记录。它们用于溯源，不是当前产品、架构或开发状态的权威来源。

## 子目录

- `reviews/`：早期项目分析和技术评审；
- `refactors/`：已经完成的模块拆分和工程重构记录；
- `decision-reviews/`：保留决策形成过程的长篇讨论稿；
- `verification/`：旧阶段的验证清单和旧测试基线。

如果历史文档中的结论与当前文档冲突，应以 `docs/README.md` 指向的当前权威文档、源码、测试和最新开发日志为准。历史文档不删除，也不把旧测试数字当作当前基线。
