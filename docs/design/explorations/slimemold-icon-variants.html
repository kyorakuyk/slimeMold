SlimeMold icon directions

四个可缩放的 SVG 母版。重点比较：品牌隐喻、工作流语义、16–32px 识别度，以及在深浅背景上的稳定性。

single accent · no watermark

01 · Route

recommended balance
有机路径 + 分支节点保留 slime mold 的生长感，同时给出输入、汇合、分支和出口的工作流暗示。

02 · Junction

workflow first
明确的节点编排语法输入节点连接中心节点，再分成两个结果节点；产品含义最直接，品牌有机感相对克制。

03 · Cell

brand first
黏菌细胞 / 自组织网络更接近品牌名称和自然智能隐喻，适合官网和大尺寸展示，小尺寸语义更抽象。

04 · S-mark

small-size first
slimemold 的 S 单线标记最适合标题栏、任务栏和 favicon；识别稳定，但工作流/节点语义主要由产品上下文补足。
